# 第一堂課 — 從零到會用 Claude Code

> 課程總覽見 [00-overview.md](00-overview.md)。
> **通用能力**：終端機 / AI 協作入門（所有 technical 工作的入口）。
> **本堂目標**：一次 session 內讓學員親手把 Claude 跑起來 + 完成第一個分析（讀自己的去識別 cohort）。
> **形式**：手把手 demo，學員跟著按。
> **刻意不教**（留後續，降低門檻）：使用技巧 / 心法（第二堂）、工作習慣三檔（第三堂）、git（第四堂）、完整 PHI（只給一句底線）。第一堂只做「裝起來 + 跑出第一個分析」，不貪多。

---

## 1-1 開場 — 終端機 vs 你熟悉的聊天介面

> 目的：架橋。學員腦中對照的是 ChatGPT / Claude 網頁，要先講清楚差別、消除「黑底白字」恐懼。

- 一句話定位：網頁聊天 = 會講話的人；Claude Code 終端機 = 坐在你電腦前、能動手做事的人。
- 五個關鍵差別（看得到什麼 / 能做什麼 / 資料怎麼進 / 結果在哪 / 長怎樣）→ 用對比表。
- 對研究的實際意義：CSV 分析「網頁來回十幾趟複製貼上」vs「終端機直接讀檔跑完」→ 這就是用終端機版的理由。
- **關鍵安撫**：你不用學指令，打中文跟它講話就好；終端機只是它「住的地方」。

### 📇 先認三個會一直聽到的詞（速覽小卡）

> 不用背、不用懂細節，先混個臉熟；後面用到會再講。

| 詞 | 白話 | 一句話 |
|----|------|--------|
| **prompt** | 你交辦的話 | 你打給 Claude 的那句指示。打中文就是 prompt，不用想複雜。 |
| **session** | 一段工作對話 | 一次 `claude` 開到關 = 一個 session；裡面它記得你講過的話，**關掉就忘**（細節第二堂）。 |
| **context** | 上下文 / 來龍去脈 | Claude「當下記得的東西」——你給的背景、讀過的檔、聊過的話。**給越清楚，答越準**（技巧第二堂）。 |

> ⚠️ 一個易混點：等下 1-2 會看到終端機的「**提示符**」`username@mac ~ %`，英文也叫 prompt，但那是「電腦在等你打字」的符號，**跟上面「你交辦的話」不是同一個東西**——看語境就懂。

## 1-2 iTerm2 — 先有舞台

> 目的：先讓他懂 iTerm2 是什麼、裝起來、看懂第一個畫面。

- iTerm2 是什麼：一個終端機 app（macOS 內建 Terminal 的更好替代）。**iTerm2 ≠ Claude**。
- 比喻：iTerm2 = 舞台，Claude Code = 台上演員；先有舞台演員才能上台。
- 為什麼用 iTerm2 不用內建 Terminal：分頁 / 搜尋 / 好設定 / 順手。
- 安裝 iTerm2：官網 iterm2.com 下載 .dmg → 拖進 Applications（零基礎最直覺，不用先懂 brew）。
- 第一次打開：一片空白 + 閃爍游標 = 正常，別怕。
- 看懂 prompt 提示符（`username@mac ~ %`）= 「電腦在等你打字」。

---

## 1-3 透過終端機安裝 Claude Code

> 目的：手把手裝起 Claude。這是學員照著貼的第一行指令，**必須正確**。

**安裝（macOS 官方推薦的 Native Install）：**

```sh
curl -fsSL https://claude.ai/install.sh | bash
```

- 這條會自動裝好、之後也會背景自動更新，零基礎不用管細節。
- （其他方式如 Homebrew `brew install --cask claude-code` 留給已熟悉的人；第一次裝走上面那條最省事。）

**確認裝好：**

```sh
claude --version    # 看到版本號 = 成功
claude doctor       # 更詳細的健康檢查（裝不起來時跑這個）
```

**啟動：** 打 `claude` 按 Enter（細節見 1-4）。

**⚠️ 一個前提：** Claude Code 需要 **Pro / Max / Team** 等付費方案，免費 Claude.ai 方案用不了（你們用 lab / 自己的席位登入 → 接 1-4 `/login`）。

**常見卡關：**

- `command not found: claude` → 裝完沒生效，**關掉 iTerm2 重開**（PATH 要重新載入）；還不行就跑 `claude doctor`。
- 系統需 **macOS 13.0 以上**、4GB 以上 RAM。

> 版本註記：安裝方式可能更新，以[官方文件](https://code.claude.com/docs/en/setup)為準（本課對齊 2026-06）。

## 1-4 在 iTerm2 裡把 Claude 跑起來

> 目的：啟動 + 登入 + 看到對話模式。

**1. 啟動** —— 在 iTerm2 打：

```sh
claude
```

按 Enter。第一次啟動會帶你登入。

**2. 第一次登入** —— 它會叫你登入，照畫面指示：

```
/login
```

- 跳出瀏覽器 → 用你的 Claude 帳號 / lab 給的團隊席位登入 → 授權 → 回到 iTerm2 就接上了。
- ⚠️ **已知坑**：團隊 / 組織 policy 改過之後，需要再 `/login` 重登一次才生效 → 若你加入團隊後覺得「權限怪怪的 / 用不了」，**先重登**再說。

**3. 啟動後長怎樣** —— 畫面進入 **Claude 對話模式**（看到輸入框、提示你可以打字）→ 現在直接打中文跟它講話就好。

> 小提醒：之後每次要用，就是「`cd` 進你的資料夾（1-5）→ 打 `claude`」這兩步。

## 1-5 讓 Claude 看到你的資料夾（最關鍵一節）

> 目的：破除「載入資料夾」的網頁版誤解，建立 Claude Code 的正確心智模型。這是學員最常卡、也最該先懂的觀念。

- **🔑 核心觀念糾正**：Claude Code **沒有「載入 / 上傳資料夾」這個動作**。
  - 網頁版：要把檔案上傳 / 拉進去它才看得到 →「載入」。
  - Claude Code：它**自動看得到你「現在人在的那個資料夾」**（working directory）。你不用載入，你用 `cd` **走進**資料夾，它就跟著站在那。
  - **心智模型一句話**：不是「把資料夾載入 Claude」，而是「**你走進資料夾，Claude 就跟著你站在那裡**」。你站哪個資料夾，它就看得到那裡的東西。
- **操作手把手** —— 三行指令，在 iTerm2 依序打：

  ```sh
  cd ~/Desktop/我的研究/cohort_analysis   # 1. 走進你的研究資料夾
  pwd                                      # 2a. 確認自己人在對的地方
  ls                                       # 2b. 看裡面有哪些檔
  claude                                   # 3. 開 Claude，它的工作範圍就是這個資料夾
  ```

  - （補充：開了 claude 之後也可叫它讀特定檔；但「先 cd 進去再開」最直覺，先學這條。）
- 打中文交辦 = 跟它講話（不用學指令語法）。
- 結束（`Ctrl-C` 兩次或打 `exit`）/ 重開 session。

### 🎯 第一次讀檔 + 第一次分析（第一堂高潮 demo）

> ✅ **直接用學員自己的真實去識別 cohort 資料**（以 ID code 去識別，非姓名 / 病歷號 → 本地分析無 PHI 問題）。動機最強、馬上對自己研究有用。

**demo 流程（手把手，每人在自己資料夾各跑一次）**：

1. 走進資料夾、確認檔在、開 Claude：

   ```sh
   cd ~/Desktop/我的研究/cohort_analysis
   ls            # 確認看得到自己的 cohort 檔
   claude
   ```

2. 用中文交辦第一個分析（**直接打進對話框**），例：

   > 讀這資料夾裡的 `my_cohort.csv`，告訴我有幾筆、幾個欄位、每欄缺值多少。

3. 撞授權提示（接 1-6）→ 教他們按 → Claude 真的讀到檔。
4. 進階一步，再打：

   > 幫我做敘述統計，並把年齡分布畫成直方圖，存成 `age_dist.png`。

   → 親眼看到結果**寫成檔案**存進自己資料夾（`ls` 就看到多出 `age_dist.png`）。
5. **成就感錨點**：他們第一次體驗 = 「AI 讀了**我自己的真實研究資料**、做了分析、存了圖」，不是玩具範例。

- ⚠️ **第一堂唯一一句 PHI 底線**（不展開，完整留第三堂）：
  - 「**Claude 在你電腦本地讀檔做分析，資料沒送出去 = 安全**；你的 cohort 用 ID code 去識別化過，更沒問題。」
  - 「但**別把整段病摘 / 病歷原文（含姓名、病歷號）貼進對話框**。本地讀去識別檔 OK，手動貼 PHI 進對話不行。」
  - 細節（共享 Project、metadata、各家 AI 服務的合規環境差異）→ 第三堂，第一堂只守這條底線。

## 1-6 授權存取（grant access）— 第一次叫它讀檔時會撞到

> 目的：學員開 claude 後第一次「叫它讀檔」會被擋兩道，不懂會嚇到 / 亂按。這章接在第一個任務當下教（提示正是那一刻跳出來的）。
> 撞牆順序：先 macOS 系統權限（B），後 Claude 逐次提示（A）。

### B. macOS 系統層權限（第一個撞到）

- 情境：iTerm2 第一次要碰 `~/Desktop` / `~/Documents` 裡的檔 → **macOS 跳系統視窗**「iTerm2 想存取你的桌面資料夾」。
- ⚠️ 研究資料常在 Desktop / Documents 底下 → **這個很容易撞**。不允許 = Claude 讀不到檔，會一直失敗。
- 做法：按「允許」；若錯過 → **系統設定 → 隱私權與安全性 → 檔案與資料夾（或完整取硬碟取用權）→ 把 iTerm2 打開**。
- （教學提醒：demo 前可先幫學員確認 iTerm2 已有權限，避免現場卡住。）

### A. Claude 逐次權限提示（讀檔 / 改檔 / 跑指令時）

- 情境：Claude 要**讀檔 / 改檔 / 執行指令**時，會跳提示問「要不要允許？」。
- 三個選項講清楚：
  - `Yes` = 這次允許
  - `Yes, and don't ask again`（同類不再問）= 信任這類動作後，同資料夾同類操作不再每次問（順手，但要懂自己在放行什麼）
  - `No` = 拒絕這次
- **這是安全設計不是故障**：Claude 動你的檔案 / 跑指令前先問過你 = 你隨時握有控制權。
- 學員心法：看得懂它要做什麼 → `Yes`；不確定 → 先看清楚再決定，或問指導者。

> 🔗 **接第二堂**：你現在「會跑」了，但還不一定「用得好」。怎麼問才有用、`/` 指令、出錯怎麼自救、session 是什麼 —— 全在[第二堂：怎麼用 Claude Code 用得好](02-using-claude-well.md)。
