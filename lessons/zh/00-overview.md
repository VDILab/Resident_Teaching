# 給臨床研究者的開發工具素養 — 課程總覽

> 對象：臨床、非工程背景，從沒碰過終端機的醫師 / 住院醫師 / 研究助理。
> 平台假設：macOS + 終端機 CLI 版 Claude Code（介面工具用 iTerm2）。
> 狀態：🚧 大綱草稿（work-in-progress），各堂為教學綱要，內容逐章展開中。

---

## 核心哲學

**用「做研究」當練習場，教的卻是「一輩子帶得走的通用 technical 能力」。**

這不是「教你跑自己的 cohort」而已 —— 是養「**會用現代工具的臨床研究者**」。研究是當下的施力點，能力是長期的投資。每個工具都有兩層：

| 工具 | 通用能力（帶得走，終身）| 研究落地（馬上有用）|
|------|----------------------|-------------------|
| 終端機 / iTerm2 | 所有 technical 工作的入口 | 跑自己的分析 |
| Claude Code | AI 協作開發 | 讀 cohort、做統計 |
| CLAUDE.md / PROGRESS / TODO | 專案管理 / 知識外部化 | 管理自己的論文進度 |
| git / GitHub | 版本控制 / 協作 / 雲端備份（終身技能）| 備份程式碼、跟團隊協作 |

- **形式**：手把手 demo，學員跟著按，每人在自己專案各跑一次。
- **平台假設**：macOS + 終端機 CLI 版（非桌面 app），介面工具用 **iTerm2**。

## 課程地圖（三堂）

| 堂 | 檔案 | 主題 | 通用能力 | 結束帶走 |
|----|------|------|---------|---------|
| **第一堂** | [01-claude-code-from-zero.md](01-claude-code-from-zero.md) | 從零到會用 Claude Code | 終端機 / AI 協作入門 | 裝起來、讀自己的去識別 cohort、跑出第一份分析 + 圖 |

| **第三堂** | [03-knowledge-externalization.md](03-knowledge-externalization.md) | 工作習慣 = 知識外部化 ⭐ | 專案管理 / 文件方法論 | 各專案有 CLAUDE.md，會維護 PROGRESS / TODO |
| **第四堂** | [04-git-and-phi.md](04-git-and-phi.md) | git / GitHub + 資料合規（PHI）| 版本控制 / 協作 / 備份 + 資料合規 | 會 commit / push、懂版本與備份、懂 PHI 規範 |

## 進階主題（規劃中 / planned）

前四堂聚焦「**本機**從零到有系統」。當學員需要跨出本機、用遠端運算資源時，會展開進階堂。**尚未撰寫，先列路線圖**：

| 堂 | 主題 | 通用能力 | 狀態 |
|----|------|---------|------|
| **第五堂** | 遠端伺服器運算（SSH + tmux + 傳檔）| 連遠端 GPU 伺服器、用 `tmux` 讓長時間 job 在背景續跑 / 斷線重連 | 🗓️ planned |

> 教學定位：本機用 iTerm2 分頁就夠，`tmux` 真正的價值在「SSH 進遠端伺服器跑訓練、關掉筆電 job 還在跑」——故留待學員實際需要遠端運算時再教。

## 一個重要前提：去識別與資料合規

本課程示範一律使用**去識別化資料**（以 ID code 取代姓名 / 病歷號）。臨床研究資料涉及病患隱私，使用任何 AI 工具前，務必確認：

- 在本機讀去識別檔做分析 = 資料留在你電腦本地，相對安全。
- **不要**把含姓名 / 病歷號的病歷原文貼進對話框。
- 各機構有自己的 IRB / 資料治理規範，以你所屬機構規範為準。

完整討論見[第四堂](04-git-and-phi.md)。
